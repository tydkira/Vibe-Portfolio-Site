A static personal site built with Astro and plain CSS. Projects live as Markdown
files in a content collection, so adding a new project is as simple as dropping
in another `.md` file.

**Highlights**

- Shared layout with header and footer
- Reusable newsletter signup form ready for a real provider
- Designed to deploy for free on Cloudflare Pages
